# Grafika bannera

Dodaj tutaj własny `Banner.png` (albo JPEG), a następnie ustaw jego bezpośredni adres w `../about-ad.json` w polu `imageUrl`.

Dla pliku `Banner.png`:
```text
https://raw.githubusercontent.com/Slogerski/Slogerski/main/remote/Assets/Banner.png
```

Limit: 512 KiB, 16–2048 px szerokości, 16–1024 px wysokości i maksymalnie 294912 pikseli łącznie, np. 1112×248 px.
Nie ma jeszcze pliku bannera; dopóki `imageUrl` jest pusty, MenuLab może wyświetlać tytuł i opis z JSON.
